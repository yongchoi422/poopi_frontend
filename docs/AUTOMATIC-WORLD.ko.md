# 자동 세계 1.2 — 구현 및 인수 기준

2026-09-30. 사용자는 ETH 기준 날씨, 완전 자동 생활·비동기 협동, 텍스트 최소화를 선택했다. 기존 원본·저장·서버를 이어 구현했으며 배포하지 않았다.

## 화면과 원본

첫 화면은 큰 마을, 날씨, 내 SOULI, 세 장소, 자동 활동 한 줄이다. 큰 정보 카드와 재료 숫자·시작/수집/건설 버튼은 제거했다. 기록·원본 선택·Web3 설명은 눌러서 연다. 접속하면 자동 채집하고 가로등 → 쉼터 → 갤러리를 순서대로 완성한다. 실제 결제·승인·전송까지 자동 실행한다는 뜻은 아니다.

배경은 청록·하늘색·옅은 녹색, UI는 밝은 중성색과 작은 파란 버튼, 빛은 따뜻한 금색이다. 특정 국적이나 코인 이용자의 색 취향을 단정하지 않는다. 원본 SVG의 색과 전경 픽셀은 유지한다. 현재 반환 SVG에는 효과/몸체의 의미별 레이어 표시가 없어 임의 분해 대신 별도 장면 효과(빛 운반·입자·수정 맥동·안개·오로라)를 사용한다. 점 형태에 얼굴·팔다리를 추가하지 않는다. 움직임 정지와 OS reduced-motion을 지원한다.

## ETH 공급과 날씨

Coinbase Exchange ETH-USD stats/ticker의 `(최근 거래 가격 / 24시간 시가 - 1) × 100`을 사용한다. ETH 변화율이지 SOULI나 전체 시장 지수가 아니다. [stats 문서](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-stats), [ticker 문서](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-ticker).

- 서버 5분 캐시·동시 요청 합치기·6초 요청 제한. HTTP Date와 마지막 거래 시각을 검증한다.
- 15분 초과·비정상 값·실패 시 새 위기를 만들지 않고 `ETH feed offline`으로 표시한다.
- 24시간 -1% 이하 비, -4% 이하 안개, +4% 이상 빛 폭풍. 나머지는 맑음. 게임용 조정값이며 시장 예측이 아니다.
- 준비 5분 → 보호 15분 → 회복 10분. 시작 사이 최소 6시간. 시작한 이벤트는 피드 장애에도 정산한다.
- 서버가 관측하지 못한 과거 새 위기를 현재 가격으로 만들지 않는다. 원천 시각은 날씨 설명에서 볼 수 있다.

## 공동 보호와 저장

- 같은 글로벌 이벤트를 동네별로 경험한다. 목표는 라운드 생성 시 정착 집 수(최대 32) × 빛 8. 새 집이 들어와도 진행 중 목표를 올리지 않는다.
- 집당 분당 빛 1. 잔액·원본 레벨 무관. 재접속·동시 요청·서버 재시작에도 한 번만 반영한다. 빛은 게임 점수이며 SOULI 지출이 아니다.
- SIWE 인증과 보유 확인 후 `/api/world/auto`로 입주한다. 마지막 검증 방문 후 2시간까지만 자동 생활·협동을 처리한다. 무기한 생산이나 지속적 보유 감시를 뜻하지 않는다.
- 성공 시 일지·누적 등불이 남고 장면에는 최대 5개를 추가 표시한다. 미달은 회복 이야기로 끝난다. 자산·기존 건물·재료를 벌칙으로 없애지 않는다.
- 하락 성공 문구는 “ETH fell. Our little town got brighter.”다. ETH만 관측하고 전체 시장 하락을 단정하지 않는다.
- Solo는 같은 실제 날씨 아래 자기 이벤트만 계산한다. 서버 동네 기여로 표시하지 않는다. 실제 관측한 시점부터 참여한다. 주변 주민은 공개 아트이며 실제 접속자 위치가 아니다.
- 개발용 `Weather preview`는 `Weather demo`로 표시하고 실제 가격/이벤트/저장을 바꾸지 않는다. production에는 해당 조작을 노출하지 않는다.

기존 개인 저장을 보존하며 자동 모드 필드를 추가했다. Solo 위기는 `souli-weather-v1`에 저장한다. 서버는 `weather_state`(글로벌), `village_defense`(동네 결과), `home_watch`(자동 참여 기간)를 사용한다. 30초 루프와 요청 시 복구가 같은 DB 트랜잭션 규칙을 공유한다.

## 검증과 남은 운영 조건

build, 프런트 로직 스크립트 6개, API/규칙 테스트 16개 통과. 테스트에는 실제 암호 서명을 쓰는 임시 지갑 2개의 협동, 중복 정산, 오프라인 2시간 상한, 재시작 후 결과, 데이터 장애·가격 경계·캐시가 포함된다. 테스트의 토큰 보유 응답과 날씨는 통제한 모의값이다. 별도로 실제 ETH 피드 응답을 확인했다. 실제 사용자 지갑을 가장하거나 자산을 이동하지 않았다.

실제 MetaMask 확장 E2E, PostgreSQL, 컨테이너, 프로덕션 스케줄러/부하 검증은 남아 있다. 서버 타이머가 멈추거나 scale-to-zero면 새 시장 사건을 실시간 관측할 수 없다. 항상 실행되는 서버 또는 별도 스케줄러를 운영 환경에서 검증한다. 현 전역 잠금/동네 순회는 비공개 베타 범위다. 판매·LP·환불·보존 전송·실시간 아바타·초대는 구현하지 않았다.

기존 souli.net은 Google Cloud Run에서 확인됐고 사용자가 이전을 미뤘다. Azure 자원 생성, 배포, DNS, 자동 배포 설정은 변경하지 않았다.
