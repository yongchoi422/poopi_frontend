# SOULI 무예산 마케팅과 성장 계획

2026년 10월 2일 KST · CMO 실행안 · ETH·Base 콘텐츠 및 영상 제작 반영

**현재 실행 상태: 준비만 진행한다.** 사용자가 개발 중에는 준비만 하라고 한 최신 결정을 적용한다. 영상·문안·운영 기준을 만들되 X 게시·예약, 사이트 배포, 판매·LP 집행은 하지 않는다. 아래 발행 흐름은 운영을 재개했을 때의 계획이다. 반복 실행이나 상시 모니터링은 설정하지 않았다.

실행 순서는 **로그인된 X 브라우저에서 직접 홍보 → SOULI 판매 → 판매대금으로 LP 조성 → Base의 Uniswap 거래 개시 → 게임과 보유자 커뮤니티의 지속 성장**이다. 게임은 **1 SOULI만 보유해도 참여할 수 있게** 만든다. 대중적인 게임으로 성장하는 것을 판매나 거래 개시의 선행 조건으로 두지 않는다.

SOULI를 **내 지갑의 작은 원본 캐릭터가 살아가는 Base의 편안한 세계**로 소개한다. 원본 아트와 실제 게임 장면으로 작지만 지속적으로 참여하는 보유자 커뮤니티를 만든다. X는 발견과 판매 소식, 웹은 제품과 구매, Telegram은 재방문과 도움을 맡는다.

사용자 결정은 추가 마케팅 현금 지출 0원이다. 기존 Codex 이용권·컴퓨터·인터넷을 활용한다는 전제이며, 사용량은 무제한이 아니다. 서버·도메인·전기·체인 수수료·판매 검토 비용까지 사라지는 사업 모델은 아니다. 유료 광고·KOL 구매·상장비·유료 API를 초기 계획에 넣지 않는다.

$500M은 다음 강세장에서 도전할 장기 목표로 유지한다. 운영 계획은 그 목표를 향해 판매·유동성·콘텐츠·게임을 순서대로 쌓는 데 집중한다. 목표를 달성 보장이나 구매자에게 약속한 수익으로 표현하지 않는다.

## 3 X에서 실제로 확인한 것

FUNGI의 [2024년 4월 1일 고정 글](https://x.com/Fungi_ERC20i/status/1774486225862156512)은 기술 소개, 원본 체험 링크, 계약 주소, 창작자 영상 인용을 한곳에 묶었다. 2026년 10월 1일 화면에는 누적 조회 211,859·재게시 299·좋아요 667이 보였다. 이는 출시 당일 실적이나 구매 전환 수가 아니다. 특정 인물을 태그했다는 사실도 그 인물의 지지를 의미하지 않는다.

같은 계정은 현재 화면상 팔로워 6,187명이다. [2026년 1월 15일 진행 예고](https://x.com/Fungi_ERC20i/status/2011799872840618153)는 조회 3,995·좋아요 25로 보였다. 두 글은 게시 후 경과 시간과 성격이 달라 성과를 직접 비교할 수 없다. 확인되는 것은 **강한 최초 기술 발표와 이후 예고형 글이 공존했다**는 점이다. FUNGI의 쇠퇴 원인을 이 표본으로 진단하지 않는다. SOULI에서는 실제로 달라진 화면을 정기적으로 보여주는 것을 실험한다.

PONKE의 [2026년 9월 20일 GM 글](https://x.com/ponkehq/status/2101657640333906083)은 3초 영상과 짧은 인사로 구성됐고 화면상 조회 6,051·좋아요 201이었다. [9월 21일 동료를 만나는 상황극](https://x.com/ponkehq/status/2101748228374909116)도 3초 영상이었다. 관측한 계정 규모는 약 13.8만 팔로워다. 이는 작은 계정의 예상 도달률이 아니라, 긴 토큰 설명 없이 캐릭터 감정을 전달하는 포맷의 참고다.

공통 가설은 게시 횟수 자체보다 **알아볼 수 있는 시각 요소, 사람이 쓰고 싶은 감정 표현, 참여할 명확한 행동**이 재사용을 만든다는 것이다. 게시 빈도·알고리즘·매출 사이의 인과관계는 이번 조사에서 검증하지 않았다.

## 4 포지셔닝과 첫 고객

핵심 문장 제안은 **Little souls. A world worth coming back to.**다. 기능 설명은 “SOULI is building a cozy world for onchain pixel companions on Base.”로 시작한다. ERC-20i는 차별화의 근거로 설명하고, 처음 보는 사람에게는 캐릭터와 세계를 먼저 보여준다. 기존 사이트의 `A LITTLE WORLD TO HODL`과 연결하되, 가격만 기다리는 공간이라는 인상은 줄인다.

FUNGI는 기술적 계보에 존중을 표시하는 출발점이다. SOULI가 공식 후계자이거나 FUNGI의 보유 권리·지원·자산을 승계한다고 주장하지 않는다. 소개 영상의 순서는 원본 캐릭터 → 마을 생활 → ETH 날씨 → 선택적으로 원본 구조 확인이다.

처음 집중할 순서는 기존 SOULI 팔로워와 보유자, FUNGI·ERC20i·온체인 아트 관심자, Base에서 직접 만드는 사람과 작은 수집 커뮤니티다. 이 집단만으로도 초기 판매와 운영을 시작할 수 있다. 일반 게이머 대중화는 선택적인 확장 방향이다. 다른 체인의 관심자는 Base의 SOULI로 연결하고 초기 유동성은 Base에 집중한다.

첫 캠페인의 작업명은 **First Neighbors**다. 20~30명의 첫 체험자에게 이름 붙이기·느낌 기록·문제 제보를 부탁한다. 참여 보상은 소개·크레딧·공동 작품 등이다. 구현되지 않은 한정 아이템, 수익, 확정 에어드롭을 약속하지 않는다. 모든 마케팅 자리에 하나의 다음 행동만 둔다.

## 5 판매 → LP → Uniswap, 게임은 1 SOULI부터

초기 전환 흐름은 `X의 캐릭터·게임 장면 → SOULI와 판매 계획 이해 → 공개된 조건에 따라 구매 → 판매대금으로 LP 조성 → Uniswap 거래 → 게임과 커뮤니티 참여`다. 게임 개발과 홍보는 판매 준비와 병행한다. 무료 체험 이용자 수나 D7 유지율을 먼저 달성해야 판매할 수 있다는 조건은 두지 않는다.

**1 SOULI로 기본 게임에 참여할 수 있게 한다.** 높은 잔액에 따른 원본 단계는 선택적인 수집 요소로 남긴다. 현재 [서버 입장 검사](../server/chain.mjs)는 `balance > 0`과 inscription 존재를 확인하며 21,000개 같은 고액 기준을 요구하지 않는다. 다만 이 코드만으로 새 구매자의 전체 입장이 검증된 것은 아니다. 공개 전에는 1 SOULI 구매 → 원본 인식 → 로그인 → 기본 생활까지 실제 흐름을 확인한다. 베타 허용 목록 등 별도 접근 조건도 함께 확인한다.

판매 준비에서 확정할 값은 판매 수량·ETH 단가·판매 기간 또는 종료 조건·LP에 넣을 판매대금 비율·페어와 투입 시점·LP 관리 방식이다. **판매대금을 LP에 사용한다는 방향은 사용자 결정으로 확정됐다.** 정확한 비율이나 잠금 조건은 아직 정하지 않았으므로 `100%`, `영구 잠금`을 문안에 임의로 넣지 않는다. 판매용 SOULI와 LP에 함께 넣을 SOULI 재고도 구분해 확보한다.

최신 [ETH 판매 구현](ETH-SALE.ko.md)은 재고를 판매하고 ETH를 수취하며, 자동 LP 기능은 없다. 따라서 자금 흐름은 `판매 수취 → 정해진 정책대로 유동성 공급 → 실제 풀 주소와 거래 링크 공개`로 계획한다. Uniswap 거래 개시 공지는 실제 풀과 양방향 거래 확인 후 게시한다.

우선 매출 목표는 SOULI 1차 판매다. 장식·테마 등 별도 게임 상품은 필요할 때 추가한다. 1차 판매대금, 게임 상품 매출, DEX 거래액은 별도로 기록한다.

## 6 추가 지출 없는 브라우저 운영

운영 재개 후의 기본 경로는 **Codex가 소재와 문안을 준비 → 로그인된 SOULI X 브라우저에서 직접 작성·게시 → 게시 결과 확인·기록**이다. 현재는 사용자의 최신 지시에 따라 준비 단계에서 멈춘다. Buffer 가입이나 유료 X API 연결을 선행 과제로 만들지 않는다.

| 소재 생산 | 기존 원본 SVG·실제 게임 캡처·확인된 변경으로 다음 3~4개 글 준비 | 원본과 개발 상태를 정확히 표시 |
| X 발행 | SOULI 계정인지 확인하고 브라우저 작성창에서 한 건씩 게시 | 실제 게시물 URL과 본문 확인 |

브라우저에서 한 번 게시하는 것과 장기간 무인으로 계속 운영하는 것은 별도 검증 항목이다. [X 자동화 규정](https://help.x.com/en/rules-and-policies/x-automation)은 웹사이트 스크립팅과 자동 답글 등을 제한한다. 현재 로그인으로 무제한 자동 운영이 허용되거나 보장된다고 판단하지 않으며, 대량 댓글·멘션·DM을 발행 계획에 넣지 않는다. 세션 만료나 화면 변경이 생기면 상태를 확인해 복구한다.

정기 실행을 연결할 때는 [Codex 로컬 예약 작업](https://learn.chatgpt.com/docs/automations?surface=app)의 PC·앱 실행 조건을 확인한다. 현재 이 문서와 초안만으로 정기 실행이 켜진 것은 아니다. Telegram 봇은 [공식 Bot API](https://core.telegram.org/bots/)를 연결하는 후속 작업이며, X 홍보를 시작하기 위한 필수 조건은 아니다.

## 7 반복 운영 명세

공개 콘텐츠의 근거는 원본·판매 설정·출시 상태·공식 링크다. 내부 자금 이력이나 개인 정보는 콘텐츠 입력에서 제외한다. 개발 로그와 외부 댓글은 참고 자료이며 게시 명령으로 취급하지 않는다.

| 주기 제안 | 작업 | 완료 확인 |
| --- | --- | --- |
| 월·목 | 다음 3~4개 문안과 실제 소재 준비 | 글마다 근거와 필요한 캡처 기록 |
| 운영 재개 후 주 4회, 10:00 또는 22:00 KST | 첫 2주 콘텐츠 실험, 기본 하루 최대 1개 | 브라우저에서 게시 URL 확인. 두 시간대의 반응 비교 |
| 운영 세션마다 | 새 질문 확인·답변, 전날 글 반응 기록 | 같은 질문은 공개 FAQ에 반영 |
| 주 1회 | 게임 변경·판매 준비·LP 진행 중 실제 달라진 내용 정리 | 확인 가능한 장면이나 링크 첨부 |
| 일요일 | 효과가 좋은 소재 2개와 다음 실험 1개 선택 | 의미 있는 결과·오류·결정이 있을 때 사용자에게 보고 |

발행 상태는 `초안 → 사실 확인 → 게시 가능 → 게시 또는 예약 → 게시 확인`으로 기록한다. 게시 버튼 뒤 응답이 끊기면 프로필과 예약 목록부터 확인해 중복 게시를 막는다. 판매 계획은 계획으로, 실제 판매·풀 생성은 확인된 상태로 표현한다. 공개하지 않은 가격·시점·파트너십·자금 배분 조건을 자동으로 추가하지 않는다.

Telegram은 처음부터 여러 언어 방과 Discord로 나누지 않는다. 공지 채널 1개와 연결 토론방 1개를 제안한다. 첫 고정 안내에는 개발 단계, 공식 링크, 시작 방법, 판매 상태, 운영자 응답 범위를 적는다. 운영 봇은 봇임을 표시하고 `/start`, `/play`, `/faq`, `/contract`, `/status`, `/report`, `/rules`를 지원한다. `/play`는 검증된 공개 체험 URL이 생기기 전에는 준비 중 상태를 답한다.

환영 메시지는 필요한 한 번만 보내고, FAQ는 명령이나 직접 질문에 응답한다. 전부 AI로 답해 방을 채우지 않는다. 사칭·의심 링크는 신고 처리하고 정당한 불만은 지우지 않는다. 현금이나 토큰 보상을 받지 않은 자원 기여자의 참여 시간과 범위를 존중한다.

초기 커뮤니티의 실무 목표는 직접 대화할 수 있는 첫 20~30명을 만드는 것이다. 이는 판매 개방 조건이나 가격 상승 예측이 아니다. 적은 사람으로 시작해 어떤 장면과 설명이 구매·참여로 이어지는지 찾는다.

매주 기록할 지표는 다음 여섯 가지다. 계측이 없는 항목은 추정으로 채우지 않는다.

1. 게시물별 확인 가능한 노출·반응·웹 유입.
2. 판매 페이지 방문과 구매 성공·실패 원인.

5. 1 SOULI 보유자의 게임 입장 성공과 다음 날 또는 다음 주 재방문.
6. 보상 없이 다시 참여하거나 작품·게시물을 공유한 커뮤니티 구성원.

웹 유입이 적으면 소재와 대상, 구매 페이지에서 이탈하면 설명과 동선, 입장 후 돌아오지 않으면 게임 경험을 고친다. 조회수 하나로 성과를 판단하지 않는다. 대규모 게임 이용자 수는 초기 판매 전략의 필수 지표가 아니다.

## 10 500M 목표의 정확한 의미

`FDV = 가격 × 전체 공급`, `시가총액 = 가격 × 유통 공급`으로 구별한다. 회사 가치·조달한 현금·게임 매출·매도 가능한 금액은 모두 별개다. 현재 검증된 SOULI 시장가격과 유통 공급이 없으므로 현 평가 대비 몇 배인지 계산하지 않는다.

| 가정 | 500M USD 유통 시가총액에 필요한 가격 | 같은 가격의 FDV |
| --- | --- | --- |
| 42M 유통, 전체 공급의 20%라는 가정 | 약 $11.9048 | $2.5B |
| 105M 유통, 50%라는 가정 | 약 $4.7619 | $1B |
| 210M 전량 유통이라는 가정 | 약 $2.3810 | $500M |

따라서 우선 내부 비교 목표는 **전체 공급 210M 기준 FDV $500M**으로 명확히 쓰고, 유통량을 확인하면 시가총액 목표를 함께 표기한다. 이는 사용자 목표를 낮추는 결정이 아니라 서로 다른 숫자를 섞지 않기 위한 작업 가정이다. 작은 거래나 높은 고정 판매가만으로 표시되는 FDV는 실질 수요의 증거가 아니다.

**1 SOULI 입장 설계로 게임 진입과 높은 원본 단계의 수집을 분리한다.** 전체 공급 210M 기준 FDV $500M의 산술 가격은 1 SOULI당 약 $2.38다. 이는 목표 가격에서의 단순 환산이며 현재 가격이나 예상 수익이 아니다. 입장에는 별도 지갑·체인 사용 비용이 있을 수 있다. 높은 원본 단계를 갖추어야 기본 게임에 참여할 수 있게 만들지 않는다.

성장 경로는 작은 보유자 커뮤니티 → 알아보기 쉬운 캐릭터와 반복되는 밈 → 실제 판매와 유동성 → 지속적인 게임 장면과 외부 소개다. 게임 이용자 1만 명 같은 대중화 수치를 먼저 달성해야 이 목표에 도전할 수 있다는 전제는 두지 않는다. 시장 평가와 함께 실제 유동성·보유 집중도·프로젝트 운영 지속성을 본다.

시장 준비 자료에는 실제 $100 / $1,000 / $10,000 매수·매도 견적의 슬리피지, 유동성 출처와 관리, 상위 보유 집중도, LP 제외 유통량 추정과 근거를 넣는다. 실제 거래가 없는 단계에는 미확인으로 표시한다. 거래량을 만들기 위한 자전거래·조직적 매수·허위 제휴·허위 희소성은 성장 수단으로 사용하지 않는다.

## 12 바로 사용할 운영 자료

별도 [첫 14일 콘텐츠](marketing/x-content-14d.json)에 영어 프로필·고정 글·14개 게시 초안과 필요한 자료 조건을 기록했다. 모든 글은 초안이며 예약 등록되지 않았다. 판매가 시작됐거나 게임이 이미 공개됐다는 문장을 넣지 않았다. 실캡처가 필요한 글은 해당 캡처와 버전 상태를 확인한 뒤 게시한다.

현재 Codex의 실행 범위는 근거 있는 소재 제작과 문안 준비다. 운영 재개 후에는 로그인된 X에서의 발행과 결과 기록을 연결한다. Telegram 연결 대상은 아직 확인되지 않았다. 실제 발행의 완료 기준은 SOULI 계정 확인, 한 건의 게시·URL 확인, 중복 방지다. 반복 실행은 별도 설정과 검증이 필요하며 현재 활성화되어 있지 않다.

다음 실행 순서는 **현재 콘텐츠·판매 조건 준비 → 운영 재개 시 X 브라우저 홍보 → SOULI 판매 → 판매대금으로 LP → Uniswap 거래 → 1 SOULI 게임과 커뮤니티 지속 운영**이다. 새로운 토큰 발행이나 체인 이전은 필요하지 않다.

## 13 조사 범위와 남은 확인

확인한 것은 로컬 제품 문서·설정, 로그인된 SOULI 계정과 FUNGI/PONKE의 일부 공개 게시물, 프로젝트 공식 사이트·백서·개발자 문서다. X의 전체 게시물 수집, 유료 도달·비공개 KOL 계약, 각 프로젝트의 전체 투자 이력과 회계, 가격 상승의 인과관계는 검증하지 않았다. 이번 비교는 무투자임을 보증하는 목록이 아니라 자금 차이를 구별한 실행 참고다.

판매 실행에서 정할 값은 판매 수량·ETH 가격·기간/종료 조건, LP 투입 비율·페어·시점·관리 방식, 판매 및 LP용 재고다. Telegram 주소·권한과 게임 공개 시점도 후속 확인 사항이다. 판매대금의 LP 사용 방향은 확정되어 있다. 현재 개발과 계획에 관한 콘텐츠는 준비할 수 있으며 발행은 사용자 요청에 따라 보류한다.

## 14 ETH와 Base를 중심으로 한 영상 운영

SOULI의 콘텐츠 기준은 **ETH 시장 분위기, Base 생태계, SOULI의 실제 개발**이다. BTC는 기본 소재로 쓰지 않는다. ETH 가격과 Base 소식은 독립적으로 확인한다. Base의 호재가 ETH 또는 SOULI의 상승을 보장한다는 식으로 연결하지 않는다. Base 정체성의 근거는 [공식 홈페이지](https://www.base.org/), 장애 확인의 출발점은 [공식 상태 페이지](https://status.base.org/)다.

브랜드 문장 제안은 **Little souls. Big feelings. Built on Base.**이다. 시장이 움직일 때 표정과 작은 행동으로 공감하고, 평소에는 원본 캐릭터와 실제 게임의 변화를 보여준다. 영상 자체에 가격·날짜·뉴스 문구를 굽지 않아 같은 소재를 재사용한다. `gm`, `fren`, `smol`, `still building`을 짧게 쓰되 모든 문장을 유행어로 채우지 않는다. 가격 상승 약속이나 무조건 매수·보유를 요구하는 표현은 브랜드 톤으로 채택하지 않는다.

| 상황 | 장면과 말투 | 당일 확인과 게시 선택 |
| --- | --- | --- |
| ETH 상승 | 두 캐릭터의 작은 점프. `eth is up. so is the mood, fren.` | 게시 직전 ETH-USD와 측정 구간 확인. 상승 원인은 확인 없이 붙이지 않음 |
| ETH 하락 | 캐릭터가 가까이 모이고 뒤로 비가 내림. `rough weather. good company, fren.` | 일반적인 시장 감정에만 사용. 체인 사고나 피해 사건의 반응 영상으로 쓰지 않음 |
| ETH 횡보·신선한 데이터 없음 | 일상·GM 장면. `gm fren. little soul, big day.` | 방향성·가격 수치 없이 발행할 수 있는 기본 소재 |
| Base의 새 앱·창작자·행사 | 새 이웃을 맞는 장면. `more builders. more little worlds.` | 해당 공식 발표의 날짜·내용·실제 관련성 확인. SOULI 제휴나 Base의 지지로 표현하지 않음 |
| Base 관련 부정적 평판·논쟁 | 필요한 경우 짧고 차분한 사실 설명 | 단순 논쟁이면 억지로 반응하지 않음. 가격 하락과 네트워크 장애를 혼동하지 않음 |
| Base 장애·보안 문제 또는 SOULI 장애 | 관련 축하·구매 유도 콘텐츠 보류, 영향 안내 | 공식 상태와 SOULI에서 직접 확인한 영향·확인 시각·다음 행동을 명시. 모르는 것은 미확인이라고 표시 |
| 장애 복구 | 실제 동작을 확인한 뒤 작은 안도감 | 공식 복구만으로 SOULI의 정상 동작까지 단정하지 않음. 토큰 매수 유도와 묶지 않음 |

우선순위는 **SOULI 이용자에게 영향을 주는 사고 → 검증된 SOULI 소식 → 관련성이 높은 Base 소식 → ETH 감정 콘텐츠 → 상시 GM**이다. 뉴스가 없으면 만들어내지 않는다. 큰 사건이 생긴 날에는 기존 예약 콘텐츠가 있는지 확인하는 절차를 둔다. 현재 실제 예약은 없다.

현재 코드의 시장 데이터는 Coinbase Exchange ETH-USD이며, 15분이 지난 값은 신선한 데이터로 취급하지 않는다. 게임의 24시간 변화 규칙은 `≤ -4%: fog`, `≥ +4%: aurora`, 그 사이 `≤ -1%: rain`, 나머지 `calm`이다. 근거는 [시장 수집](../server/market.mjs)과 [게임 규칙](../src/lighthouse/market-world.mjs)이다. 이것은 현 개발 코드의 규칙이며 모든 홍보 영상이 이 게임 장면을 재현한다는 뜻은 아니다. 가격이 게임 내 토큰 잔액이나 보상을 바꾼다고 설명하지 않는다.

운영을 시작하면 첫 2주는 **주 4개 원본 게시물**로 실험한다. 감정·캐릭터 2개, 실제 개발 1개, Base 또는 커뮤니티 1개가 기본이다. 확인된 중요한 사건이 있으면 예정 소재를 교체한다. 기본 상한은 하루 1개 원본 홍보 글이며 서비스 안내는 별도로 필요한 만큼 전달한다. 예전 14일 초안은 연속 매일 발행 지시가 아니라 소재 저장고로 유지한다. 같은 영상·문구를 연속 반복하거나 수량을 채우려고 타인에게 멘션하지 않는다.

첫 2주에는 조회수만 보지 않고 영상 재사용·공유, 관련 있는 답글, 프로필·웹 방문, 실제 체험으로 이어진 반응을 기록한다. 플랫폼이 제공하지 않는 시청 지표는 미측정으로 둔다. 이후 실제 공개 동선이 생기면 체험·입장·판매 전환을 연결한다. $500M 목표는 내부 성장 목표로 유지하며 밈마다 가격 목표를 넣지 않는다.

## 15 배너와 80편 밈 영상 패키지

메인 배너는 사용자가 선택한 짙은 파란 마을과 라벤더·코럴 캐릭터 구성을 유지한다. [1080p 파일](../output/marketing/souli-film/souli-hero-1080p.mp4)은 다운로드한 720p 원본을 로컬에서 Lanczos로 확대한 1920×1080, 8초, 무음 H.264 파일이다. Flow의 1080p 내보내기는 저장에 실패했으며 이 파일을 Flow 업스케일 출력으로 표현하지 않는다. 원본과 [변환·검증 기록](../output/marketing/souli-film/hero-1080p-handoff.json)을 함께 보존한다. 홈페이지는 변경하지 않았다.

새 홍보 방향은 **Little moments: 진지한 소울리에게 생기는 사소한 재난**이다. 매회 원본 SVG·장소·소재·색감·물리적 농담을 바꾼다. 계단형 캐릭터, 실제처럼 보이는 작은 세트, 과하게 진지한 반응이 시리즈를 묶는다. 배너에서 잘라 쓴 옛 GM 및 비슷한 상승·하락 영상은 보관하되 신규 발행 후보에서 제외했다.

[80편 재생·캡션 목록](../output/marketing/souli-film/meme-pack/index.html)과 [전체 기획](../output/marketing/souli-film/meme-pack/episodes.json)에 기존 40편과 새 40편을 저장했다. 새 추가분은 41–80번으로, 영화관·탁구장·사탕 가게·달·미니어처 기차역 등 다른 SVG와 장소를 사용한다. 캐릭터 변형이 눈에 띄던 기존 12편(01·02·04·05·06·07·10·13·16·17·18·19)을 다시 제작해 교체했다. 에스프레소 편은 소품 중심의 움직임으로 바꿔 얼굴 교체를 줄였다. 새 20편에는 세탁방·자판기·DJ·박물관·레이싱·공항·우산·도서관 등 다른 장소와 반전을 사용했다.

80개 MP4는 모두 8초, 1280×720, 무음 H.264이며 전체 디코딩을 통과했다. 교체 12편과 추가 60편은 각 16개 시점의 프레임을 비교했고, 유지한 8편은 앞서 확인한 6프레임 검수를 유지했다. 생성된 질감·가려진 부분·소품의 해석은 원본과 다를 수 있다. 실제 게임 플레이나 SVG의 픽셀 단위 복제, 완벽한 반복 루프를 의미하지 않는다. 11·15편은 반전이 약한 조용한 반응용으로 남기고 메인 추천에서 제외했다.

완성본은 [Google Drive souli 폴더](https://drive.google.com/drive/folders/1PFx3kre_rFMnmxNmTPYDVZhHKVNu3KND)에 저장한다. `01-final-videos`는 검수 MP4 80개, `02-homepage-banner`는 배너와 출처 기록, `03-captions-and-index`는 ZIP·캡션·전달안이다. 실패한 생성본은 로컬 수정 이력에만 보존한다. 업로드 파일은 개수·부모 폴더·바이트 크기를 다시 읽어 확인한다.

향후 하루 한 편을 고르면 최대 80일치 재고가 된다. 실제 개발·제품 소식과 섞어 올릴 때는 더 오래 사용할 수 있다. 처음부터 고정 빈도를 약속하지 말고 첫 2주의 공유·재사용·관련 답글·프로필 방문·실제 체험을 보고 조정한다. 같은 배경·소재·감정을 연속 사용하지 않고 캡션은 두 번째 농담을 맡긴다. 현재 게시·예약·배포는 하지 않았다.

## 16 홈페이지 랜덤 배너와 Moments 페이지 제안

**메인은 추천 6편 중 방문마다 한 편, 갤러리는 80편 전체**를 제안한다. 메인 후보는 01 에스프레소, 06 토스터, 16 소파, 21 양말, 28 종이 자동차, 37 로봇청소기다. 같은 세션에는 선택을 유지하고 `Meet another soul` 버튼으로 다른 영상을 고르게 한다. 영상은 8초 한 번 재생 후 마지막 장면에서 멈추는 것을 기본으로 한다. ETH 방향이나 당일 Base 소식이 필요한 편은 랜덤 메인에서 제외한다.

사이트 바탕은 웜 화이트, 텍스트는 짙은 잉크색으로 정돈하고 영상의 다양한 배경은 그대로 살린다. 제목과 실제 게임 진입 CTA는 고정 위치에 둔다. 영상은 16:9 전체 구도를 유지하며, 모바일에서는 제목 아래에 놓아 반전 소품이 잘리지 않게 한다. 승인된 파란 마당 배너는 별도 대표 영상으로 유지한다.

`/moments` 페이지는 지갑 연결 없이 감상할 수 있는 포스터 그리드와 상황 필터를 둔다. 카드에서는 짧은 캡션, 재생과 공유를 제공한다. 한 번에 하나만 재생하고 화면에 가까워진 포스터를 불러온다. 공개 페이지에는 내부 제작·검수 기록을 노출하지 않는다. 생성 애니메이션과 실제 게임 화면을 구분해 소개한다.

[동작하는 메인 시안](../output/marketing/souli-film/meme-pack/homepage-concept.html), [웹 담당 전달안](../output/marketing/souli-film/meme-pack/website-handoff.txt), [파일 매핑](../output/marketing/souli-film/meme-pack/website-media-manifest.json)을 준비했다. 실제 웹 프로젝트나 다른 채팅에는 변경·메시지를 보내지 않았다. Drive는 보관과 전달용이며 실제 홈페이지는 해당 프로젝트의 정적 파일 또는 미디어 경로로 배포해야 한다.


## 17 추가 40편 제작 기록 (41–80)

새 원화 40개는 Codex 내장 이미지 생성기로 원본 SVG를 참조해 만들었고, Flow Omni 1.1 Flash에서 가로 720p·8초로 영상화했다. 새 40편 전부 16개 시점의 프레임을 검수했다. 41·46·47·58·70·73·74·77·80은 눈·얼굴·몸체 변형이 있는 생성본을 제외하고 재생성본으로 교체했으며, 74는 세 번째 버전을 채택했다. 49는 마지막 정상 장면을 1.25초 유지하는 편집으로 끝의 변형을 제외했다. 원본과 제외본은 로컬 revisions에 남겨두었다.

최종 전체 80개는 길이 8초·1280×720·24fps·무음 H.264로 확인했고 파일 전체 디코딩 및 서로 다른 SHA256 해시를 확인했다. Drive 신규 40개는 이름·MIME·부모 폴더·바이트 수를 재확인했다. 모든 프레임이 SVG와 완전히 일치한다는 뜻은 아니며, 47의 마지막 외부 손 소품과 68의 작은 패치 색 변화는 검수 기록에 명시했다.

41–80의 실제 프롬프트와 채택 영상 정보는 [전체 기획](../output/marketing/souli-film/meme-pack/episodes.json), [이번 검수 기록](../output/marketing/souli-film/meme-pack/batch3-editorial-working.json)에 있다. X 게시·예약이나 라이브 웹사이트 배포는 하지 않았다.
