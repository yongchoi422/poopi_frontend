## LP 실행 시점과 수령 지갑 — 추천안, 아직 미확정

- **판매 개방 후30일 안에 첫 수동 LP 실행 여부를 검토하고 결과를 공개**하는 운영 일정을 추천한다. 이는 자동 실행, 최소 유동성 보장 또는 새로 승인된 강제 기한이 아니다. 실제 첫 실행일/조건을 정해 공개한 후 판매를 여는 편이 명확하다. 완판을 기다려야 하는 규칙은 두지 않았다.
- 실제 LP 전 고정가 판매를 중지하고 누적 구매 ETH의50%를 계산한다. 기존 풀/가격/슬리피지/별도 SOULI를 검토하고 수동 서명한다. LP 개설 후 같은 고정가 판매를 무심코 재개하지 않는다.
- LP의 만기 수령 지갑은 **별도 자산 회수가 가능한 개인 지갑**을 추천한다. A/B/C 운영권은 이 잠금에 자동으로 이어지지 않는다. A를 쓰는 선택도 가능하지만 해당 키를 잃으면 다른 두 키로 자동 복구되지 않는다. 별도3키 회수 구조를 넣으려면 추가 설계/검증이 필요하다.
- 현재 판매 controller를 LP beneficiary로 지정하지 않는다. 해당 계약은 임의 LP를 인출할 수 없다.
- 첫 LP 실제 입금 후 최소365일이 지나야 해제되도록 설정하고 확인한다. 배포/입금이 지연돼 설정한 입금 기한을 넘기면 새 잠금 후보를 만든다. 실제 UTC 만기는 입금 영수증과 같이 공개한다.
