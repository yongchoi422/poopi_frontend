390×844 비교: 홈4831→3720px, 구매1693→1229px, 구매연결버튼1064–1111→754–803. 원본예시는 지정구매품이 아니므로 클릭상품카드를 없애고 가격/레벨 버튼으로 안내한다. LP 미생성·수동50:50·게임Cooking·자동환불없음은 계속 표시. 확인범위는 브라우저크기/동선/자동테스트이며 전환율 개선을 보장하는 사용자실험은 아니다.

2026-10-04. 실제 공개 `souli.net`, `/buy/`를 데스크톱과390×844 모바일에서 읽고 기존 Vue/지갑/원본조회 코드를 대조했다. 정량 사용자 실험이나 전환율 분석을 한 것은 아니다. 아래는 관찰에 근거한 개선 제안이며 이번 검토에서 새로운 홈페이지 개편을 배포하지 않았다.

## 사업 목표와 화면 순서

| 우선순위 | 목표 | 홈페이지가 전달할 것 |
|---|---|---|
| 1 | 현재 SOULI를 이해하고 구매 완료 | 기존 Base 토큰, 내 지갑의 원본 inscription, 지불액·받는 것·현재 조건 |
| 2 | 세계관에 관심을 갖고 재방문·공유 | 영상 속 성격, 내 소울 보기, 준비되는 개인 방, 사진 공유 |
| 3 | 정식 게임 개발 방향을 이해 | 개발 중이라는 사실과 실제 초안. 날짜·보상·완성을 구매 보장으로 붙이지 않음 |

판매가 사업상1순위여도 첫 화면은 소울의 매력을 눈으로 보여준다. 영상/캐릭터 + 한 줄의 구체적 가치 + 하나의 주 구매버튼을 같이 둔다. 세계관은 장문으로 설명하는 별도 숙제가 아니라 구매하고 싶은 이유와 보유 후 애착을 만드는 표현이다.

추천 방문 흐름: **영상에서 눈길 → 무엇을 받는지 이해 → 가격·조건 확인 → 구매 → 내 inscription → 내 방/공유**. 정식게임은 이 흐름 안에서 Cooking으로 짧게 연결한다. 원본아트는 현재 가능하고 실제지갑3D방은 아직 미연결이다.

## 유지할 것

- 브랜드 파랑·금색, 명확한 눌림 버튼, 제공된6편 영상과16:9 구도. 전면 재디자인은 필요하지 않다.
- 홈 첫 구매CTA는390px에서도 top418/bottom483으로844px 첫 화면에 들어온다. 영상 때문에 구매버튼이 완전히 숨는 상태는 아니다.
- 지갑 연결 전 원본 외형 예시, 수량 선택, ETH가격 확인. 실제 승인 전 검토 단계와 별도 사용자 동의는 유지한다.
- 현재 재고의 체인 조회, 게임Cooking, 자동환불 없음, LP미생성·수동50:50 표시. 기술상세는 펼쳐서 볼 수 있는 구조를 유지한다.
- 원본 inscription 24×24 전체 보기/저장/공유. 3D는 원본을 바꾸는 새자산이 아니다.

## 다음 홈페이지 구조

1. **Hero:** 영상, 짧은가치설명, GetSOULI, 샘플보기. 기존보유자용MySOULI 입구.
2. **What you get:** 실제원본예시, 토큰량→형태라는관계, 외형은지정구매가아님. 지금가능한보기·공유를시각적으로.

4. **Your little corner:** 당장은원본보기, 방이준비되면 실제프리뷰와진입. 미래게임Cooking은작은예고영역으로.

## LP 시점에 대한 정리

현재계약은전량완판후자동LP가아니다. 실제매출의50%를수동LP예산으로배정하고별도SOULI를짝지을계획이다. 첫누적140만목표와추가280만은재고운영계획이며LP강제실행조건이아니다. 사용자가완판후로정할수도있지만지금은실행일미정이다. 실행시기확정전에는'완판하면자동상장/즉시잠금'을약속하지않는다.
