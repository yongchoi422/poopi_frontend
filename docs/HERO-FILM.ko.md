## 최신 홈페이지 정리

**최신 배치 변경(1.29):** 사용자가 비교 후 Doodles처럼 전체 폭 영상 배너를 승인했다. 901px 이상은 영상 위 고정 제목/게임·구매 안내와 투명 헤더, 900px 이하는 전체16:9 영상 다음에 제목·버튼을 배치한다. 영상 카드 테두리, 부가 문장, 시각적 긴 캡션을 제거했다. 영문 캡션은 영상의 접근성 설명으로 남긴다. 세로 높이는100svh까지, 원본은contain으로 잘리지 않으며 초광폭의 남는 공간만 현재 포스터로 흐리게 채운다. 다른 다섯 포스터/영상을 배경용으로 불러오지 않는다. 320/390/1024/1280/2560px 가로 넘침 없음. 교체 전후 제목의 문서 좌표가 동일하고, 새로고침 선택 복원·차단 후 직접 재생·reduced-motion 영상 요청0개 확인. 최종 빌드/영상 검사 통과,4173에서도 재생·스타일 확인. 최신 화면은 `logs/hero-film/immersive-desktop.png`, `immersive-mobile.png`이며 아래 이전 배치 기록보다 우선한다. 공개 배포 없음.

후속 요청에 따라 `SouliHome.vue`를 짧은 문구와 시각 안내 중심으로 정리했다. 첫 화면은 Play free / Get SOULI, 코인→캐릭터, 원본 6개 캐릭터, 실제 게임 장면 순서다. Get SOULI는 판매 미개시 표시와 기존 비활성 구매 패널로 연결한다. 최종 페이지의 320/390/1200/1920px에서 가로 넘침 없음, 모바일 details를 펼친 상태에서도 확인. 구매 안내는 결제 버튼 비활성 상태를 표시하며 게임으로 돌아갈 수 있다. 빌드 미리보기4173의 메인/백서 연결도 확인했다. `npm.cmd test` 전체 통과(프런트 검사, 서버23개, 빌드, 런타임 패키지). 영상 브라우저 기록은 37→01→06→16→21→28 순서를 반복하며 15회 재생을 보여준다. `logs/hero-film/continuous-cycle.json`에 저장. 최종 스크린샷은 `continuous-desktop.png`, `simple-mobile.png`이며 이전 화면보다 우선한다. 아래 초기 “다른 홈페이지 섹션 유지”와 Pause/1회 설명은 후속 사용자 변경 전 기록이다.

**최신 재생 결정:** 사용자가 “Pause 없이 6개를 계속 쭉” 재생하도록 변경했다. 초기의 1회 재생/마지막 프레임 유지 요구보다 이 결정이 우선한다. 시작 영상은 세션 선택을 복원하거나 무작위로 고르고, 이후 01→06→16→21→28→37→01 순으로 계속 순환한다. 자동 전환도 sessionStorage에 저장해 새로고침 시 마지막 선택부터 시작한다. Pause/Replay 버튼은 제거했다. 동작 줄이기·데이터 절약·브라우저 차단에서는 자동 연속 재생하지 않으며 직접 재생 버튼을 제공한다.

## 적용

- `src/site/HeroFilm.vue`: 기존 메인의 게임 장면 카드를 대체한다. 게임 자체와 다른 홈페이지 섹션은 유지한다. 데스크톱은 제목 옆, 760px 이하에서는 제목/CTA 아래. 16:9 + contain으로 원본 구도를 보존한다.
- `src/site/hero-films.mjs`: 01/06/16/21/28/37 여섯 편, 영문 캡션/대체 설명, 무작위 선택. `souli-hero-film-v1` sessionStorage 키로 탭 세션의 선택을 유지한다. 저장소 접근 불가 시 현재 페이지 메모리에서 작동한다.
- `public/media/souli-moments/v1/`: 영상6개/포스터6개, 총11,151,569bytes. 제공 원본을 재인코딩 없이 복사했다. 서비스 경로 `/media/souli-moments/v1/episode-XX.mp4`와 `episode-XX-poster.jpg`를 사용한다. Drive/제작용8892/output 경로는 앱의 미디어 주소에 없다.
- `docs/hero-film-media.json`: 선택된 파일의 크기/해시 보존. 원본 자료실40편과 이전 파란 마당/업스케일 파일은 건드리지 않았다. Moments 갤러리를 새로 만들지는 않았다.

무음/playsinline으로 한 편이 끝나면 다음 편을 재생하고 여섯 편 후 다시 순환한다. **Meet another soul ↻**는 현재와 다른 영상을 즉시 선택한다. 동시에 video 요소 하나만 존재하며 다음 파일을 미리 요청하지 않는다. 재생 전에는 선택된 포스터만 표시하고, 허용된 자동재생 또는 직접 재생 클릭 시에만 src를 연결한다. 자동재생 거절 시 포스터·재생 버튼, 미디어 오류 시 포스터·재시도 안내를 표시한다. 캡션은 자동 전환 때마다 스크린리더가 끼어들지 않도록 live region으로 두지 않는다.

`prefers-reduced-motion`, `navigator.connection.saveData`, 숨겨진 탭에서는 자동재생하지 않는다. 모션/데이터 설정 변경과 탭 숨김은 재생을 중지한다. 탭으로 돌아오면 설정이 허용할 때 자동으로 이어 재생한다. 모션/절약 상태에서 직접 재생한 영상은1편만 재생한다. 브라우저가 saveData 신호를 제공할 때 이를 존중하며 제공하지 않는 설정을 추측하지 않는다. 재생/교체 중 늦은 Promise와 이전 video 이벤트는 현재 선택을 덮어쓰지 않는다.

현재 브랜드의 코발트/골드와 여백·타이포를 유지한다. 영상에는 ANIMATED SHORT를 표시한다. 게임 진입은 기존 `./lighthouse.html`의 무료 playable preview, 공유 마을은 invite-only beta, 실제 토큰 판매는 닫혀 있다는 기존 문구를 유지한다.

- 개발 전용 `tmp/hero-film-qa.html`: 같은 Vue 컴포넌트에 자동재생 거절/모션 설정/Save-Data 신호를 모사해 브라우저에서 검사했다. 차단 포스터→직접 재생 성공. 모션/절약 상태에서는 src 없음, play 호출0회, MP4 리소스 요청0개. 일반 자동재생에서는 MP4 요청이 선택된1편뿐이었다. 이 검사는 실제 휴대폰 OS 설정을 직접 조작한 검사는 아니다.
- `node scripts/test-hero-films.mjs`: 세션 복원, 오래된 선택값, 차단된 저장소, 중복 없는 선택, 자동재생 정책, 12개 파일/원본 해시 일치 통과. 이 테스트는 제작 output 폴더 없이도 실행된다.
