# SOULI 월넛 방 — 실제 3D 모델링 초안 v2

**2026-10-11 후속:** 현재 루트 화면은 [Porcelain Quarter — 정문과 작은 광장](PLAZA-README.ko.md)이다. 다섯 소울이 자동으로 방어하고, 문이 뚫리면 물감이 광장으로 퍼졌다가 청소·수리되는 실제 3D 장면을 `http://127.0.0.1:4318/plaza.html`에서 확인한다. 건축 GLB와 브라우저 검증 결과도 함께 저장했다.

**2026-10-03 후속:** 루트 화면은 [다섯 소울의 하얀 미니어처 세계](MINIATURE-README.ko.md)로 이어졌다. 이전 [숲](GROVE-README.ko.md)은 `grove.html`, [맨해튼](ROOFTOP-README.ko.md)은 `rooftop.html`에 남아 있다. 이 문서의 기존 월넛 방·입체화 도구는 `http://127.0.0.1:4318/room.html`에서 그대로 확인할 수 있다.

2026-10-03. 방과 가구를 실제 메시로 만든 첫 모델링 초안이다. 이전 이미지 컨셉의 장면을 단순한 형태와 적은 재질 정보로 다시 구성했다. 최종 미술 품질이나 게임 완성을 의미하지 않는다.

후속 실험: 사용자 요청에 따라 **원본 2D ↔ 입체 소울 3D** 전환과 두께·모서리·회전 조절을 추가했다. 기본 화면은 입체 소울이다.

## 확인하기

이 폴더에서 `npm install`, `npm start` 후 `http://127.0.0.1:4318/room.html`을 연다.

- **게임 화면:** 고정 카메라의 방에서 원본 SVG 또는 선택형 입체 소울을 표시한다.
- **3D 모델 둘러보기:** 드래그로 실제 모델을 회전하고, 스크롤로 확대한다. 입체 소울은 방 안에 남고, 2D 오버레이는 이 보기에서 숨긴다.
- **원본 도트 / 입체 소울:** 같은 공개 원본을 두 방식으로 비교한다.
- **두께·모서리 둥글기·돌려보기:** 입체 형태를 조절한다. 이 로컬 미리보기의 설정만 브라우저에 저장한다.
- **소울 가까이 / 정면 보기:** 확대하거나 앞면을 맞춰 도트와 입체감을 확인한다.
- **저녁 조명:** 같은 모델의 조명과 창밖 색을 바꾼다.
- **원본 선택:** 공개 샘플 6종과 작은 dot를 비교한다.
- **방 GLB 저장:** 방의 메시·재질·가구 계층·기본 카메라·조명을 저장한다.
- **소울 GLB 저장:** 현재 소울과 두께·모서리 설정으로 캐릭터 모델을 저장한다. 방과 소유권 데이터는 포함하지 않는다.
- `A little moment`는 소울의 짧은 기울임과 커피 머신 레버의 동작 확인이다. 생활 사건 시스템은 아직 연결하지 않았다.
- `Keep this`는 미리보기 반응만 보여준다. 실제 앨범 저장은 아직 없다.

## 제작한 개체

벽·바닥·창틀·창밖, 커튼, 러그, 탁자·매트, 커피 잔 2개, 안락의자·쿠션, 수납장, 커피 머신·레버, 선반·책, 화분·잎, 펜던트 조명, 액자. 주요 가구는 각각 독립된 그룹이다. 창밖과 액자 그림에는 평면 메시를 사용했다.

`Soul_on_table`, `Coffee_interaction`, `Sit_anchor`, `Pour_anchor`, `Water_anchor`, `Light_anchor`를 빈 개체로 넣어 후속 행동의 기준 위치로 사용할 수 있게 했다. 이 위치를 만들었다는 것과 해당 행동을 구현했다는 것은 다르다.

원본 SVG는 보존한다. 알려진 렌더러 배경 사각형만 분리했고, 전경 도트 7종의 좌표·크기·색이 모두 원본과 동일한지 확인했다. 입체 모드에서는 SVG의 그리기 순서대로 겹친 색을 정리하고, 연결된 픽셀의 외곽을 하나로 이어 두께를 준다. 앞면은 원본의 최종 도트 색을 유지하는 비조명 재질이고, 옆면·뒷면은 연결 영역의 주색을 사용하는 조명 재질이다. 뒷면에는 임의의 얼굴을 만들지 않는다. 모서리 옵션은 두께 방향의 가장자리 처리를 조절하며, 완전히 둥근 생물형 캐릭터 생성 기능은 아니다.

공개 샘플은 이 미리보기의 캐릭터 선택용이며 소유권이나 사용자 지갑을 의미하지 않는다. 온체인 자산이나 게임 소유권은 이 실험에서 변경하지 않는다.

## 게임에 넣는 제작 흐름

3D 모델 원본 → 고정 카메라로 방·앞쪽 소품·빛과 그림자를 필요한 레이어로 렌더링 → 원본 2D 소울과 사건 애니메이션 합성.

현재 뷰어의 실시간 3D는 미술 제작과 모델 검토용이다. 실제 서비스 게임을 실시간 3D로 확정한 것은 아니다. 앞으로 가구별 가림 레이어, 반응 애니메이션, 낮·밤·비 렌더, 색이 다른 소울의 가독성을 제작한다. 최종 재질, 정돈된 UV, 실제 이벤트 애니메이션, 충돌·이동 로직, 성능 최적화는 후속 작업이다. `.blend` 파일은 아직 생성하지 않았다.

기존 앱의 게임·구매·계약·배포 코드는 변경하지 않았다. 이 폴더는 독립된 제작 초안이다.

## 재현 및 검증

`npm start`가 켜진 상태에서 `node verify-and-export.cjs`로 기존 2D 합성 방을, `node verify-soul-volume.cjs`로 입체 소울을 확인한다. 검증 스크립트의 Playwright 경로는 현재 Codex 로컬 런타임용이다. 다른 환경에서는 해당 require 경로만 설치된 Playwright로 바꾼다.

모델은 Three.js 0.186.1의 메시와 재질로 작성했다. [GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html)로 GLB를 만들고 GLTFLoader로 다시 읽었다. 게임 뷰에는 [OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html)를 사용한다. 미리보기는 외부 API 호출 없이 로컬 서버와 로컬 Three.js 패키지로 실행된다.
