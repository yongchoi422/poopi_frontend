# SOULI — A little world, together

2026-10-03. 사용자가 선택한 **하얀 미니어처 세계를 더 크게 만들고, 여러 소울이 함께 생활·방어하는 초안**이다. 이전 숲과 맨해튼 초안을 보존한 독립 로컬 화면이다.

## 열기

이 디렉터리에서 `npm start` 후 <http://127.0.0.1:4318/miniature.html>. 기본 진입도 이 화면이다. 맨해튼은 `rooftop.html`, 숲은 `grove.html`, 기존 방과 입체화 도구는 `room.html`에 남아 있다.

## 더 넓은 세계, 다섯 소울

바닥은 30×20 논리 단위, 600 면적의 사각 마을이다. 기존 옥상의 색칠 영역 약 90 면적보다 약 6.7배 크다. 실제 바닥 판은 외곽 테두리까지 32×22다. 밝은 타일·긴 방벽·중앙 수문·공동 집·흰 주택·시계탑·열주·계단·벤치·조형 나무를 코드로 모델링했다. 실물 랜드마크 복제가 아닌 작은 건축 모형의 세계다.

큰 설명 패널을 없애고 마을이 화면 너비 대부분을 사용한다. `+`/`−` 확대, 화면 드래그, 다섯 주민 카드로 따라보기, `Whole town` 전체 보기. 모바일은 처음부터 1.7배로 확대하고 같은 기능을 제공한다. 전경을 모두 담는 시점에서는 캐릭터가 작아지므로 주민 카드를 눌러 가까이 볼 수 있다.

| 샘플 주민 | 역할 | 실제 결과에 주는 영향 |
|---|---|---|
| Gm fren / Sir HODL | 입구 방어 2명 | 세척 발사체로 적의 체력을 줄이고 경로상 뒤로 밀어낸다 |
| Cozy degen / Lil moon | 거리 청소 2명 | 안쪽의 가까운 오염을 찾아 이동하고 실제 타일을 복원한다. 넘어온 적도 씻는다 |
| Grass toucher | 방벽 수리 1명 | 방벽 압력을 낮추고, 열린 방벽을 복구·보강한다 |

다섯 캐릭터는 기존 공개 SVG 샘플의 원본 전경을 같은 결정적 입체 생성기로 표현했다. 구매·잔액·소유 지갑과 연결된 주민이 아니다. 외형이나 원본 크기로 능력을 계산하지 않으며 역할은 초안의 고정 배정이다. 지금은 유저 여러 명의 온라인 협동이 아니라 **한 기기에서 자율적으로 움직이는 주민 다섯 명**이다.

## 자동 사건

8초 준비 → 45초 사건 → 16초 휴식 → 다음 하늘을 반복한다. 버튼으로 배치하거나 시작할 필요 없다. 논리상 210초를 화면 45초로 압축하며 실제 시장 시간과 무관하다.

세 접근로가 하나의 입구로 모인다. 닫힌 방벽 앞에서 적이 멈추고 압력이 쌓인다. 방어 소울의 공격은 적을 실제 경로에서 뒤로 밀고, 맞은 생물은 짧게 눌리는 모습으로 반응한다. 첫 물결을 버텨낸 뒤 더 큰 무리에서 방벽이 뚫릴 수 있다. 물감은 열린 틈에서 안쪽으로 약 3초 동안 파도처럼 번지며 실제 오염 셀을 바꾼다.

수리 소울은 방벽 앞으로 가서 복구하고, 청소 소울은 번진 물감을 찾아 나눠 씻는다. 수리된 방벽은 압력 한도가 80에서 120으로 올라간다. 기본 샘플 난수 423의 양 날씨는 첫 물결 방어 → 한 번의 붕괴 → 복구·보강 → 내부 정리로 끝난다. 이는 튜닝한 기본 상황이고 모든 조합의 성공을 보장하는 규칙은 아니다.

HUD의 `Clean inside`는 전체 지도보다 **방벽 안쪽 생활 구역**의 청결도에 초점을 둔다. 바깥 물감은 남을 수 있다. 종료 시 내부 92% 이상·방벽 복구를 정리 완료 조건으로 사용한다. 정리가 덜 되어도 원본·집·소유 자산을 없애지 않는다.

## 날씨와 저장

- Violet tide와 Coral shower는 각각 ETH −4.2%/+4.2%라는 비교용 샘플. 실제 가격 피드는 없고 화면에 DEMO를 표시한다. 상승 쪽은 더 빠른 방문자와 작은 비산, 하락 쪽은 넓은 자국을 사용한다.
- 시작된 사건은 날씨·데모 변화율·난수·버전을 고정한다. 사건 중 선택 버튼은 잠긴다. 두 날씨 모두 회복 가능하다.
- `souli-white-neighborhood-v1` IndexedDB에 저장한다. 기존 숲·맨해튼 DB를 건드리지 않는다. 최근 24개 기억, JSON 내보내기, revision 충돌 거부, 새로고침 중복 정산 방지를 포함한다.
- 장기 부재 후에는 진행 중 한 사건만 끝내고 충분한 휴식부터 재개한다. 닫힌 브라우저에서 서버가 계속 시뮬레이션하지 않으며 무한한 사건/보상 누적을 계산하지 않는다.
- `Still`은 반복 흔들림과 입자를 줄이고 물감 파도를 단순 원으로 표시한다. 논리 진행은 유지한다. 화면이 숨겨지면 렌더링을 멈춘다.

## 범위와 검증

지역 간 이동, 여러 유저, 계정 백업/복원, 구매 원본, 캐릭터 수 편집, 실시간 ETH, 영구 마을 건설은 아직 연결하지 않았다. 이 화면에서 API 기반 3D 생성이나 게임 서버를 호출하지 않는다.

`miniature-rules.mjs`가 바닥·역할·결정적 사건·생활 시간을, `miniature-world.mjs`가 모델과 카메라를, `miniature-store.mjs`가 별도 저장을, `miniature.mjs`가 화면과 진행을 담당한다. 기존 원본 입체화·생물·풀링 효과를 재사용한다. 지도와 건물은 재질별 병합/인스턴싱, 효과 입자 320개·원 80개·파도 10개, 방문자 동시 20개 이하, 렌더 목표 30fps·DPR 상한 1.5로 제한한다.

`node --test test-grove.mjs test-rooftop.mjs test-miniature.mjs`로 기존 25개와 새 6개 규칙을 검사한다. 새 검사는 역할을 각각 끈 비교로 방어·청소·수리가 실제 결과를 바꾸는지, 첫 물결 방어와 복구, 양 날씨의 결정성·객체 상한, 장기 부재·중복·잘못된 저장을 포함한다.

서버 실행 후 `node verify-miniature.cjs`로 실제 WebGL의 다섯 주민, 자동 방어, 범람과 수리, 중간 재로드, 카메라 확대/따라가기/이동, 저동작 모드, 320/390px, 날씨 변경, 저장 충돌을 확인한다. 결과는 `miniature-verification.json`, 화면은 `miniature-*.png`다. 소프트웨어 WebGL 검수이며 실제 휴대전화 프레임과 발열은 별도 검증이 필요하다.

이번 실행은 규칙 31개와 브라우저 검증을 통과했다. 기본 첫 사건은 다섯 주민 전원의 기여, 실제 밀어내기 82회, 방벽 붕괴 1회·복구 1회, 내부 청결 100%로 끝났고 중간 재로드 뒤에도 결과가 유지됐다. 범람 화면에서 draw call 99·삼각형 47,134개·방문자 16개였으며, 물리 기기의 성능 측정값은 아니다.
