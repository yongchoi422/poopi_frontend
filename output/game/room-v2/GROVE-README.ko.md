# SOULI — Little Lantern Grove 플레이 초안

2026-10-03. 사용자가 승인한 [판타지 기획](../../../docs/SOULI-FANTASY-WORLD-PLAN.ko.md)의 첫 플레이 순환을 확인하는 독립 로컬 초안이다. 실제 ETH 날씨·구매·지갑·공동 서버는 연결하지 않았다.

이 숲 초안은 **자동 생활 + 민트/보라 색 점령**이다. 사용자가 제안한 스플래툰의 영역 칠하기에서 출발해, 기존 숲과 소울에 독자적인 생물 모델·발사체·색 번짐을 붙였다. 참고 원리: [닌텐도 공식 Turf War 설명](https://splatoon.nintendo.com/en/gameplay/). 닌텐도의 모델·텍스처·캐릭터·음원은 사용하지 않았다. 이후 요청한 **랜드마크 청소·방벽 붕괴·물감 범람**은 별도의 [맨해튼 옥상 초안](ROOFTOP-README.ko.md)으로 이어가며 이 숲과 저장을 보존한다.

## 열기

이 디렉터리에서 `npm install`, `npm start` 후 <http://127.0.0.1:4318/grove.html>. 루트는 최신 [하얀 미니어처 세계](MINIATURE-README.ko.md)로 연결된다. 상단 `Manhattan` 링크는 옥상으로 연결된다. 이전 월넛 방과 입체화 도구는 <http://127.0.0.1:4318/room.html>에 유지한다.

## 해볼 수 있는 일

기본은 **완전 자동 관찰 모드**다. 배치나 시작 버튼을 누를 필요가 없다.

1. 소울이 16초 동안 숲길을 따라가 돌아온다. 첫 방문에는 빛나는 씨앗을 발견한다.
2. 날씨에 맞는 세 시설을 9초 동안 한 개씩 놓는다. 안개에는 등불·차임·울타리, 오로라에는 달빛 그릇·차임·울타리를 고른다. 현재는 날씨별 규칙을 사용하며 생성형 AI를 호출하지 않는다.
3. 색 점령 방어가 자동으로 시작된다. 논리상 3분·세 무리를 6배속 30초로 보여준다. 생물은 이동하며 보라색을 남기고, 소울과 시설의 공격은 민트색으로 덮는다. 민트 땅은 적을 늦추며, 보라 땅은 적을 조금 빠르게 한다.
4. 5초 동안 돌아와 기억을 남기고 20초 동안 쉰다.
5. 다시 탐험을 나간다. 데모에서는 다음 외출 때 안개와 오로라가 번갈아 온다. 실제 ETH 시세나 생산 게임의 하루 주기는 아니다.

`Arrange it myself`를 누르면 수동 배치와 날씨 선택을 펼친다. 진행 중인 탐험·방어·귀환은 마무리하지만 다음 방어는 사용자의 시작을 기다린다. 시설을 선택하고 1~6번 설치 지점을 누른다. 모바일에는 같은 지점을 고르는 큰 버튼도 제공한다. 세 시설까지 배치하며, 같은 시설은 옮길 수 있고 새 네 번째 종류는 기존 시설을 교체한다. 준비가 되면 `Let the fog arrive` / `Watch the aurora arrive`로 시작한다. `See how it went`는 같은 고정 결과까지 연출을 건너뛴다.

`Let soul decide`로 자동 생활을 다시 켠다. 배치 단계에서 켜면 소울이 날씨에 맞춰 준비를 다시 시작한다. 이미 진행 중인 전투의 입력은 어느 모드로 바꿔도 그대로 유지한다. 자동/수동 선택도 이 기기에 저장한다. 이전 버전의 저장은 기억과 원본을 보존하며 자동 모드를 기본으로 추가한다.

`Follow soul`은 소울을 가까이 따라본다. `Still`은 주변의 반복 움직임을 줄이고 날아가는 발사체·비산 입자를 단순한 바닥 원으로 표시한다. 이동·점령 판정·전투 자체는 계속 진행한다. 원본 선택에는 공개 샘플 6개와 작은 dot가 있고 지갑의 소유 목록을 의미하지 않는다.

화면의 **Soul / Wild**는 전체 칠할 수 있는 땅에서 각 색의 비율이다. 남은 회색은 중립이다. 종료 때 민트 면적이 보라보다 넓고 등불 빛이 남아 있으면 `Our color held`. 동률·보라 우세·등불 소진이면 다음 시도를 남긴다. 결과의 색은 귀환·휴식 동안 유지하며 다음 외출 때 새 바탕으로 돌아간다. 여러 지역을 영구 점령하는 확장 지도는 아직 구현하지 않았다.

## 실제로 작동하는 범위

- 코드로 만든 야외 거점, 집, 숲·물길, 두 접근로, 여섯 설치 지점, 네 종류의 3D 시설.
- 원본 전경을 유지하는 기존 24×24 입체 생성기. 소울은 등불 앞을 순찰하며 씨앗 지팡이로 공격한다. 뿔 달린 씨앗 생물·기어오는 버섯 생물·날개가 움직이는 나방은 공유 부품을 인스턴싱한 새 3D 모델이다.
- 실제 공격 사건을 재생하는 양측 발사체·꼬리·착탄 입자·차임 파동·등불 피격 색 반응. 별도 장식 타이머가 공격을 지어내지 않는다. 효과 풀은 입자 320개·원 80개로 제한한다.
- 집을 제외한 바닥의 동일 면적 셀 606개로 점령 판정과 표시를 함께 계산한다. 바닥 색은 논리 프레임이 바뀔 때 CanvasTexture로 갱신하며, 렌더 프레임마다 저장하거나 네트워크로 전송하지 않는다. 번짐 외곽은 시각적 보간이며 점수는 셀 수 기준이다.
- 위치·종류·날씨가 결과에 영향을 주는 결정적인 논리 계산. 안개는 발견과 지연, 오로라는 빛나방 유도가 중요하다.
- 20명의 방문자를 세 무리로 생성하며 논리 프레임은 181개로 제한한다. 폭풍이 끝날 때 남은 방문자는 떠난 것으로 구분하며 방어한 수에 더하지 않는다.
- 전투 시작 때 날씨·배치·난수·규칙 버전을 고정한다. 현재 샘플 조건의 결과를 비교하기 위해 같은 난수 422를 사용한다. 새 전투는 규칙 v2이며 기존 저장의 진행 중 v1 전투는 원래 계산으로 끝낸다.
- IndexedDB에 자동/수동 선택·개인 진행·배치·선택 원본·최근 24개 기록을 저장한다. 화면을 열어 두면 외출과 휴식이 반복된다. 오래 비운 뒤에는 진행 중이던 한 번의 외출까지만 마무리하고 충분히 쉰 뒤 재개한다. 브라우저가 닫힌 동안 실행되는 서버나 무제한 오프라인 전투·보상 계산은 없다.
- 새로고침 중복 완료 방지, 과거 시계로 진행 취소 방지, 여러 탭의 저장 revision 충돌 방지. 자동 전환끼리 충돌하면 최신 저장을 읽어 이어간다. 수동 수정의 오래된 revision은 거부한다. 오류를 기존 저장의 조용한 초기화로 처리하지 않는다.
- JSON 내보내기. 이 초안에는 파일 가져오기·클라우드 백업·다른 기기 자동 복원이 없다.
- 탭을 숨기면 렌더링 중지, 재방문 시 시간으로 정산. 브라우저 저장 불가 시 저장되지 않는 세션임을 표시한다.
- 반복 식생·적 인스턴싱, 픽셀 비율 상한 1.5, 30fps 렌더 목표, 고정 배경 그림자 캐시, 소울 접지 그림자. 실제 모바일 발열·프레임 실측은 아직 별도다.

게임 재료나 실제 토큰 보상은 지급하지 않는다. 성공·미달 모두 집과 원본은 그대로 남는다. 이 단계의 목적은 사용자가 명령하지 않아도 소울의 생활이 이어지고 다시 보고 싶은지, 누가 어떤 땅을 되찾는지 장면에서 읽히는지 확인하는 것이다. 다중 지역 점령·대규모 숲의 영구 변화·무기 수집·멀티플레이는 후속 범위다.

## 파일과 검증

| 파일 | 역할 |
|---|---|
| `grove.html`, `grove.mjs` | 화면·입력·플레이 순환·복귀 |
| `grove-world.mjs` | 실제 3D 세계와 연출 |
| `grove-creatures.mjs` | 세 생물의 부품 모델·눈·걷기·날개, 공유 메시 풀 |
| `grove-paint.mjs` | 바닥 색과 발사·착탄·파동 효과 |
| `grove-turf.mjs`, `grove-combat.mjs` | 점령 셀·색 덮어쓰기·v2 전투와 실제 공격 사건 |
| `grove-rules.mjs` | 시설·경로·시간·결정적 전투 규칙 |
| `grove-store.mjs` | IndexedDB 저장, revision 확인, 기존 저장 보존 |
| `grove-originals.mjs` | 공개 원본의 전경 정리 |
| `test-grove.mjs` | 발견·배치·오프라인·중복·전투 입력 고정·날씨 차이·저장 형식 검증 |
| `verify-grove.cjs` | 실제 브라우저 플레이, 재로드, 7개 원본, 모바일, 저장 충돌 검증 |
| `verify-grove-autonomy.cjs` | 입력 없는 자동 순환, 단계별 배치, 다음 외출, 자동 저장 충돌, 모드 전환 검증 |
| `verify-grove-color.cjs` | 생물·공격 효과·점령 화면·재로드·결과·저동작 모드·모바일 검증 |

`node --test test-grove.mjs`와 서버 실행 중 `node verify-grove.cjs`, `node verify-grove-autonomy.cjs`, `node verify-grove-color.cjs`로 확인한다. 소프트웨어 WebGL의 동시 실행은 짧은 준비 장면을 놓칠 수 있으므로 브라우저 검증은 순서대로 실행한다. Playwright 경로는 이 Codex 환경의 번들 경로다. 결과는 `grove-verification.json`, `grove-autonomy-verification.json`, `grove-color-verification.json`, 검수 이미지는 `grove-*.png`다.

규칙 테스트 19개 통과. 색 덮어쓰기·점령 집계·결정적 공격 사건·날씨별 대응·등불이 살아 있어도 땅을 빼앗기면 미달이 되는 결과·v1 저장 호환을 포함한다. 브라우저에서는 실제 생물과 발사체, 양측 점령 비율, 중간 재로드, 휴식 중 결과 색 유지, 저동작 모드, 수동 배치, 7개 원본, 320/390px 표시를 검증한다. 자세한 결과는 위 JSON에 기록한다. 소프트웨어 WebGL 검수이며 실제 휴대전화 FPS·발열을 검증한 결과는 아니다.

## 후속 작업

실제 기기에서 캐릭터 가독성·프레임·발열을 확인한 뒤 시설 작동 피드백과 소울 행동을 개선한다. 그다음 지속적인 탐험 계획, 생활 사건 12개, 장기간 복귀 요약, 기상 관측 이력, 계정 백업을 연결한다. 지금 결과를 완성된 프로덕션 게임이나 실제 시장 사건으로 안내하지 않는다.
