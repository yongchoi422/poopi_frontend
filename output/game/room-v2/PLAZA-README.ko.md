# Porcelain Quarter — 정문과 작은 광장

2026-10-11. 다섯 소울이 지키는 흰 미니어처 광장이다. 기존 자동 방어 규칙에 새 건축 모델, 연결되는 물감 표면, 침략자, 공격·청소 효과, 카메라, 소리를 붙여 한 장면의 완성도를 확인한다.

**방어 연출 2차 개선:** 물줄기가 도착하는 순간의 침략자 변형·밀림·짧은 색 변화, 발사 반동, 충격 파편과 파문을 추가했다. 문은 압력을 받을 때 떨리고, 뚫리는 순간 빠르게 열렸다가 반동이 가라앉는다. 실제 범람 구간은 약 1.7초로 압축하고 그 전의 버티는 구간은 조금 늘렸다. 곡면으로 이어지는 물감 전면과 반사·두께, 청소 중 밝은 경계·물자국·거품을 적용했다. 짧은 카메라 충격과 겹친 물·금속·저음 효과를 추가했으며, `Still` 또는 운영체제 동작 줄이기 설정에서는 카메라 충격과 추가 입자를 끈다.

## 실행과 관찰

이 폴더에서 `npm install`, `npm start` 후 **http://127.0.0.1:4318/plaza.html** 을 연다. 루트 주소도 이 화면으로 이어진다. 모든 실행 자산은 로컬 서버에서 읽는다.

들어오면 배치나 시작 버튼 없이 약 **83초** 주기가 진행된다. 준비 6초, 방어·범람·복구 62초, 휴식 15초다. 첫 작은 물결을 막은 뒤 **36.5초에 정문이 뚫리고 38.2초까지 물감이 빠르게 밀려든다.** 약 50초에 문이 수리되고, 휴식 구간에서는 광장 안쪽이 100% 깨끗해진다. 두 데모 색의 실제 붕괴 시점에 각각 연출 시간을 맞춘다. 다음 주기는 물감 색이 바뀌며 이어진다. 화면을 숨긴 동안에는 관찰 시간이 멈춘다.

- **방어 2명:** 실제 침략자에게 물방울을 발사해 밀어낸다.
- **청소 2명:** 오염된 위치로 이동해서 바닥의 물감을 지운다.
- **수리 1명:** 문으로 이동해 복구한다. 문짝이 다시 닫힌다.

결과는 기존 `miniature-rules.mjs`의 결정적 시뮬레이션에서 가져온다. 청소 담당을 제외하면 실제 복구 결과도 달라진다. 원본 SVG의 최종 도트 좌표·색을 보존한 입체 소울 5종을 사용하며, 몸통이 작은 원본은 표시 크기를 조정했다. 원본의 장식 도트도 유지한다.

## 조작

- 아래 소울 카드: 해당 소울을 가까이 따라본다.
- **Whole square:** 광장 전체 보기와 기본 보기 전환. 소울 따라보기도 해제한다.
- 장면 드래그: 카메라 위치 이동.
- **Sound off / on:** 사용자 클릭으로 소리를 켜거나 끈다. 물 발사, 범람, 수리 소리는 Web Audio로 합성한다.
- **Still:** 장식 움직임과 날아가는 입자를 줄인다. 자동 방어 규칙은 계속 진행된다. 운영체제의 동작 줄이기 설정도 반영한다.
- **Replay:** 현재 색의 이야기를 처음부터 재생한다.
- **Violet tide / Coral tide:** 데모 색을 바꾸고 다시 시작한다.
- **Take a photo:** 현재 화면을 SOULI 표기와 함께 PNG로 저장한다. 최대 변 길이는 1600px이다.

## 장면 제작

흰 석재 아치 정문, 청록색 양문, 황동 테두리와 압력 표시등, 시계탑, 서로 다른 지붕의 건물, 기둥 회랑, 가로등, 벤치, 화분과 광장 바닥을 실제 메시로 만들었다. 흰 바닥과 짙은 청록색 받침, 황동 선이 장면의 경계를 만들고 소울과 물감이 색의 중심이 된다.

침략자는 물감 통과 물방울 형태다. 방어 시 발사 궤적·충돌 입자, 문이 뚫릴 때 넓은 물감 전면, 청소 거품, 수리 입자를 표시한다. 물감은 실제 오염 셀을 두 장의 마스크로 연결·보간하는 표면이며, 지워진 자리에서는 원래 바닥이 드러난다. 표면 높이·반사·잔물결은 셰이더 연출이다. 유체 역학 시뮬레이션은 구현하지 않았다.

재질별로 정적 건축 메시를 묶고, 침략자와 효과는 인스턴스·재사용 풀로 그린다. 화면 갱신 목표는 30fps, 픽셀 비율 상한은 1.5이며 2048 그림자 지도를 필요한 때 갱신한다. 재생을 되감으면 그림자도 갱신한다. 이 설정은 실제 기기에서 지속 30fps를 보장한다는 뜻은 아니다.

## 모델과 소스

| 파일 | 용도 |
|---|---|
| `plaza.html`, `plaza.mjs` | 화면, 자동 시계, 조작, 사진 저장, 초기화·정리 |
| `plaza-model.mjs` | 수정 가능한 절차적 건축 모델 원본 |
| `plaza-world.mjs` | 조명, 그림자, 카메라, 렌더러 |
| `plaza-actors.mjs` | 원본 소울과 도구, 침략자, 행동 애니메이션 |
| `plaza-paint.mjs` | 실제 점유 상태에 연결된 물감 표면과 공격·청소 효과 |
| `plaza-timeline.mjs` | 기존 규칙의 결과를 83초 관찰 장면으로 보간 |
| `plaza-beats.mjs` | 방어·붕괴의 속도 조절, 물줄기 도착 시각, 감쇠하는 충격 |
| `plaza-audio.mjs` | 사용자 선택으로 재생하는 합성 효과음 |
| `souli-porcelain-quarter.glb` | 건축과 문 모델. 6,595,572바이트, 재읽기 확인한 메시 49개 |

GLB는 Blender 등에서 열 수 있는 건축 자산이다. 실행 중 소울, 물감 셰이더, 방어 규칙, 효과음은 포함하지 않는다. 건축의 정적 부분은 렌더링을 위해 재질별로 합쳐져 있으므로 소품 형태를 바꾸려면 `plaza-model.mjs`를 수정하고 다시 내보내는 것이 편하다.

이전 `room.html`, `grove.html`, `rooftop.html`, `miniature.html`은 그대로 남아 있다. 기존 앱의 구매·지갑·계약 및 별도 waiting-room 코드는 이 작업에서 변경하지 않았다.

## 검증

규칙 검증:

```powershell
node --test test-grove.mjs test-rooftop.mjs test-miniature.mjs test-plaza.mjs
```

기존 31개와 광장 7개를 합쳐 **38개 통과**. 자동 방어부터 문 붕괴, 실제 오염 상태, 청소·수리, 보간, 두 색의 역할별 기여를 확인했다. 2차 개선에서는 시간 변환의 단조성과 역변환, 1.7초 범람, 타격 시각, 원래 결과·점유 상태 보존도 확인한다.

서버를 실행한 상태에서:

```powershell
node verify-plaza.cjs
node verify-plaza-feel.cjs
node export-plaza.cjs
```

브라우저 검증 **11개 통과**. 다섯 원본 앞면의 픽셀 일치, 방어·범람·복구, 소리 켜기·끄기와 이벤트 예약, Still, 실제 PNG 다운로드, 320px·390px 모바일 배치, 색 전환·재시작, 자동 시간 진행과 숨김 이벤트, 반복 재생 후 자원 수 유지, 다음 색의 자동 시작을 확인했다. 기록된 JS 오류와 외부 요청은 0개다. GLB는 내보낸 뒤 다시 읽어 확인했다.

`plaza-verification.json`, `plaza-model-verification.json`에 결과가 있다. `plaza-calm.png`, `plaza-breach.png`, `plaza-cleaning.png`, `plaza-rest.png`, `plaza-mobile-390.png` 등은 실제 실행 화면이다. 검증 스크립트는 이 컴퓨터의 Playwright 경로를 기본으로 사용하며, 다른 환경에서는 `PLAYWRIGHT_MODULE` 환경 변수로 설치 경로를 지정할 수 있다.

검증 환경은 데스크톱 Chrome headless ANGLE/SwiftShader다. 실제 모바일 GPU에서의 발열·지속 프레임률, 스피커로 들은 음질은 아직 검증하지 않았다. 자동 검사의 숨김 상태는 visibility 이벤트를 모사한다.

2차 연출 검증은 `plaza-feel-verification.json`에 별도로 저장한다. 타격 반응·문 파편·카메라 충격·연결된 물결·청소·복구, 곡면 좌표와 법선의 유한성, Still, 오디오 예약, 두 데모 색의 범람, 반복 후 자원 수를 검사했다. 캡처는 `plaza-feel-hit.png`, `plaza-feel-breach.png`, `plaza-feel-flood.png`, `plaza-feel-clean.png`다. 물감은 점유 마스크와 곡면·셰이더로 연출하며 실제 유체 역학 계산을 수행하지 않는다.

현재는 미술과 자동 행동을 검토하는 독립 장면이다. 공개 샘플 소울 5종과 데모 날씨를 사용하며, 실제 ETH 시세·소유권·영구 진행 저장·오프라인 보상은 연결하지 않았다. 게임용 런타임에 외부 모델 생성 API 비용은 없다.
